# 原神 圖鑒

離線可用的原神資料圖鑒：**角色 134 名、武器 246 把、聖遺物 63 套**，含技能天賦、命之座、推薦配裝、有效詞條、畢業面板參考與培養素材。

## 怎麼看

直接雙擊 **`index.html`** 用瀏覽器開啟即可（不需要架伺服器、不需要連網）。

上方四個分頁：**角色 / 武器 / 聖遺物 / 培養計算**。前三個各自有獨立的篩選、搜尋與排序。
手機上圖鑒一排顯示四個。

### 角色

篩選：元素／武器／星級／定位／**特殊體系**／技能功能／成長屬性／性別／體型／年齡層／地區

- 同一列多選＝聯集（選「風＋冰」= 風或冰）；不同列＝交集
- **特殊體系**只列需要專門配隊的機制（月綻放／月感電／月結晶／星爍／星擴散／星超導／夜魂）；蒸發融化凍結這類一般反應人人可打，當篩選沒有鑑別度，已移除
- **特殊體系**與**技能功能**是「全部符合」：同時選「減抗」和「治療」= 兩者都有的角色
- **技能功能只列能提供給隊友的能力**，自己吃的增益不會出現
- 技能功能下方的「來源」可切 **主動／被動／命座**，例如「減抗 + 主動」只列出靠 E／Q 直接減抗的角色

點卡片開角色詳情，六個分頁：

| 分頁 | 內容 |
| --- | --- |
| 資料 | 元素、武器、定位、體型、突破加成、特殊戰鬥體系、技能功能標籤 |
| 面板 | **Lv90 基礎面板**、**有效詞條**（沙／杯／冠／副詞條排名）、**參考面板**與本站試算 |
| 天賦 | 天賦優先級＋普攻／戰技／爆發／固有天賦全文，**每條技能旁標出它提供哪些團隊功能** |
| 命座 | C1～C6 全文，關鍵命座金框標出並附說明，**每條命座旁標出它提供哪些團隊功能** |
| 配裝 | **天賦優先級**、推薦聖遺物、**有效詞條推薦（主詞條／副詞條排名）**、推薦武器、關鍵命座、參考面板（聖遺物與武器都帶圖示，可點進去看詳細資料） |
| 素材 | 突破 6 階素材、天賦 1→10 素材、合計與摩拉 |

### 武器

246 把（已排除 24 個武器外觀）。篩選類型／星級／副屬性，排序可依基礎攻擊或新增順序。
詳情含 Lv90 基礎攻擊與副屬性、**精煉 1～5 階全文**、突破素材，以及「哪些角色推薦這把」（可點回角色）。

### 聖遺物

63 套。詳情含 2 件／4 件套效果、五個部位的名稱與圖鑒文字，以及「推薦給哪些角色」。

角色頁的推薦聖遺物與武器都帶圖示，**點下去可以看該裝備的完整資料，看完按左上角「← 返回 ○○」回到原本的角色**（可以一路往下點，返回會照原路退回來）。

### 培養計算

多目標的素材計算機，設定會存在瀏覽器裡。

- 按「＋ 加入角色」用**圖示挑選**（跟圖鑒一樣的卡片，可搜尋），武器也是圖示挑選
- 每個目標可設定**角色等級**（現在 → 目標）、**三個天賦各自的等級**、**武器與武器等級**
- 預設是「Lv1／天賦 1」練到「Lv90 ↑／天賦 10」，每一欄都能改；等級選單的 `↑` 代表已完成該階突破
- 右邊列出所有需要的素材，填入目前擁有的數量後會即時算出還缺多少
- **多個角色需要同一種素材會自動合併計算**
- **同一系列的素材會排在一起**（低階在上、高階在下），方便直接看合成關係
- **低階素材多出來時會自動用 3→1 合成往上補**（寶石、怪物掉落、天賦書、武器突破素材都吃這個規則），並標示「合成補 N」
- 可切換「只看還缺的」
- 角色經驗書與武器精鍛礦由所需經驗換算，摩拉一併算出


## 哪些資料是推斷的？（資料出處分級）

每個角色頁都會標示詞條與聖遺物的來源。整份專案的分級如下：

### A. 官方遊戲資料（解包，可直接信）
元素、武器類型、星級、體型、地區、生日、上線日、**技能天賦全文**、**命之座全文**、突破加成、
武器數值與精煉效果、聖遺物套裝效果與部件、**所有培養素材與數量**、等級成長曲線與經驗表。
來自 Project Amber 與 AnimeGameData，原始回應都留在 `data/_raw/` 可自行核對。

### B. 由官方數值計算（公式明確，可驗證）
- **Lv90 基礎面板**：初始值 × 官方成長曲線 ＋ 第 6 階突破加成。驗證過與遊戲內完全一致。
- **武器 Lv90 基礎攻擊與副屬性**：同一套算法。
- **培養計算機的素材需求與經驗書換算**：直接用官方素材表與經驗表加總。

### C. 程式從技能原文自動擷取（規則產生，可能有漏）
- **技能功能標籤**（減抗、團隊增傷、攻擊力加成…）：逐句掃描技能與命座原文。
  只保留能提供給隊友的效果，會排除「受益者是角色自己」的句子。
- **成長屬性**：找技能裡「基於…生命值上限／防禦力／元素精通」判斷傷害吃哪個屬性。
- **「傷害視為月曜／星系反應」判定**：據此決定空之杯要不要走元素傷害加成。
  依據是月反應的機制（已查證，見下）：`月反応扱いダメージ` 的特性是「可暴擊、無視敵人防禦、
  元素精通加算、**不吃傷害加成**」，所以這類角色的元素傷害加成杯完全沒有收益。
  受影響的是奧黛塔、桑多涅、冰主、莉奈婭；統整表涵蓋的月曜角色（菲林斯、茲白、奈芙爾、
  菈烏瑪、哥倫比婭、伊涅芙）原本就沒給元素傷害加成杯。
  ※ 只是「元素對得上、能參與該反應」的角色（例如凝光、荒瀧一斗、萬葉）不算，
  他們自己的傷害仍是一般元素傷害，元素傷害加成杯照樣有效。
- **特殊戰鬥體系標記**：角色的**技能或命座原文有提到該反應**就標記，代表配得上這個體系
  （自己打出、把一般反應轉成它、增幅它、或把它列進觸發條件都算）。目前 56 名角色有標記。
規則分別在 `tools/build-data.js` 的 `RULES` 與 `tools/build-stats.js`。

### D. 社群統整表（110 名角色，非本站推斷）
聖遺物、主詞條、副詞條排名、天賦優先級、參考面板，逐列轉錄自 HoYoLAB
「[全角色聖遺物套裝、參考面板統整](https://www.hoyolab.com/article/38343132)」（更新至法爾伽）。

### E. 查證自攻略站（4 名角色）
洛恩、桑多涅、奧黛塔、莉奈婭 —— 不在社群統整表內，另外查攻略站補上聖遺物、天賦優先級與副詞條。

### F. 本站推斷（準確度最低，請自行判斷）
**還是推斷的只剩這些**：亞蘿伊、奇偶（男／女）、尼可、布倫妮、阿羅夏，以及旅行者 14 種元素形態。
這些角色的聖遺物、詞條、面板目標是依技能文本與規則推導的，角色頁會標「本站依技能文本推導」。

另外**全部角色**的以下欄位都是本站人工判斷，不是官方也不是統整表：
**定位**（主C／副C／輔助／治療／護盾）、**機制標籤**、**特殊戰鬥體系**、**推薦武器**、**關鍵命座**、
以及「本站試算」那一段的畢業面板數字。定位有依統整表校正過，武器有用官方總表驗證存在且不是武器外觀。

## 檔案結構

```
index.html              圖鑒主頁（唯一要開的檔案）
data/
  characters.js/.json   角色（含天賦、命座、面板、詞條、素材）
  weapons.js/.json      武器
  artifacts.js/.json    聖遺物
  materials.js/.json    素材總表（511 種）、合成鏈（121 條）、等級經驗表
  characters.csv        Excel 用（UTF-8 BOM，不含天賦全文）
  _raw*                 所有原始 API 回應與成長曲線，可自行核對
images/
  icon/ splash/         角色頭像與立繪
  element/              七元素圖標
  weapon/ artifact/     武器與聖遺物圖標
  item/                 培養素材圖標
tools/
  roles.js              ★ 定位／機制標籤／一句話特色（手動維護）
  builds.js             ★ 特殊體系／武器／關鍵命座／查證過的詞條（手動維護）
  reference.js          ★ HoYoLAB 社群統整表轉錄（聖遺物／詞條／天賦優先／面板）
  build-stats.js        ★ 面板計算假設 ASSUME 與詞條例外 OVERRIDE
  build-data.js         產生角色資料，並自動擷取技能功能標籤
  build-equip.js        產生武器／聖遺物資料、培養素材與合成鏈
  validate.js           配裝驗證器（名稱、武器類型、套裝條件）
  fetch-detail.sh       下載角色天賦／命座
  fetch-equip.sh        下載武器／聖遺物明細
  fetch-images.sh       下載角色頭像／立繪
  fetch-equip-icons.sh  下載武器／聖遺物／素材圖標
  update.sh             一鍵更新（以上全部跑一遍）
  serve.js              可選的本機 http 伺服器（node tools/serve.js → localhost:5177）
```

## 更新

出新角色或新裝備時，在 Git Bash 執行：

```bash
bash tools/update.sh
```

接著手動補新角色的 `tools/roles.js` 與 `tools/builds.js`，再跑 `node tools/build-data.js` 與 `node tools/validate.js`。
其餘（天賦、命座、功能標籤、基礎面板、有效詞條、畢業目標、培養素材）都是自動產生的。
